RShort v3 - Deployment Instructions

This file is for you only. It is excluded from deployment via .cloudflareignore so it never gets published to your Worker.

1. Prerequisites

Install Wrangler (Cloudflare's CLI)

npm install -g wrangler

Log in

wrangler login
If you manage several Cloudflare accounts with named Wrangler profiles, activate one first with wrangler auth activate <profile-name>.

2. Create the D1 database

wrangler d1 create rshort3_db

Copy the database_id from the output into wrangler.toml under [[d1_databases]].

3. Apply the schema

wrangler d1 execute rshort3_db --remote --file=./schema.sql

4. Set your secrets

These are never stored in the repo. Wrangler will prompt you for each value.

wrangler secret put JWT_SECRET
wrangler secret put ROOT_USERNAME
wrangler secret put ROOT_PASSWORD
JWT_SECRET: any long random string (32+ characters). You can generate one with openssl rand -base64 32.
ROOT_USERNAME can be a plain username or an email address.
The root admin will be forced to change ROOT_PASSWORD on first login.

5. Deploy

wrangler deploy

Your worker will be live at https://rs3.<your-subdomain>.workers.dev (or your custom domain, if you attach one in the Cloudflare dashboard).

6. First login

Go to /login and sign in with the ROOT_USERNAME / ROOT_PASSWORD you set as secrets. You will immediately be asked to set a new password.

7. Local development (optional)

wrangler d1 execute rshort3_db --local --file=./schema.sql
wrangler dev
Local dev also needs local secrets - create a .dev.vars file (already covered by .gitignore) with JWT_SECRET, ROOT_USERNAME and ROOT_PASSWORD lines.
